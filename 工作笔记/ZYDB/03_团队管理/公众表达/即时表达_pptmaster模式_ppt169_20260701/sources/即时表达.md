# 表达内容
公众发言（半书面）和书面表达区别：
所谓的公众发言（半书面）：以口头为介质、以书面为底稿，经得起听众审查的公众发言。
半书面 = 口头说出来的话 + 书面写下来的底稿 + 听众预期的审查。
- **前端**：你能说出来的流畅、自信、有节奏的口头语言。
- **后端**：你藏在PPT里、数据里、逻辑链里的严谨底稿。
- **护城河**：你预判的“听众可能会挑战的点”和对应的答案。
### 00 目的决定形式

表达的形式和策略，由“要达成什么”决定。如果只是为了“完成安排”而开口，所有的技巧（结论前置、术语翻译、自信流畅）都会变成**“行尸走肉般的套路”**。因为你的潜意识知道：这次表达没有“要改变什么”的野心，所以大脑拒绝全力运转。
### 01时间有限性

大家的注意力有限（你的演讲效用窗口有限），大家的耐心有限（说太多浪费大家时间，引起反感）
### 02时间线性
口头表达话说完就没了，听众没法倒带。顺”着听觉习惯，用短句、重复和口语词，确保信息一次过。用长句、复杂的逻辑嵌套和高密度术语，因为读者有充足的时间去拆解。所以文章要抓重点（例如只抓三点），忽略复杂论证，语言表述简化。
要主动标定重点。（复述或者PPT标题）
### 03认知带宽
知带宽有限，需要“低压”信息。允许有废话、铺垫和语气词（嗯、啊、那么），这些是给听众大脑休息的“缓冲带”。们是带着“审视”或“决策”的目的在听。他们不能随便插话打断（除非你主动问），又不能走神（因为会后要表态）。他们的大脑在努力做两件事：**理解你说了什么 + 判断你说的对不对**。这个双线任务，就是你说的“极高负担”。
### 04权威来源（情感 ）
信任建立于**“自信流畅”**和**“眼神交流”**。哪怕逻辑有瑕疵，只要说得斩钉截铁，听众的直觉会被带着走。权威建立于**“数据支撑”**和**“逻辑自洽”**。哪怕文笔枯燥，只要引用来源真实、推导严密，读者会默认其为“专业资料”。


## 表达方式



即时表达本质上是一种认知压榨，观点要嘛提前就准备好了，要嘛再思考也来不及了（未经打磨漏洞百出），还不如选择一个虚的却安全的观点，所谓的思考不过是调取+筛选，找到安全的观点并且组织语言。即时表达更重要的是表达方式。

表达方式的几个底层逻辑：
1、流畅性启发。人们在做判断或决策时，会下意识地依赖“信息处理的主观体验”——即大脑处理信息的难易程度，而不是仅仅依赖信息的客观内容。**感觉轻松 = 感觉正确**

1、场景表达模式
钩子（领导，关于A项目，我需要您**XXXXXX**）
+结论   
+重要的观点摘要 
+行动指南。
