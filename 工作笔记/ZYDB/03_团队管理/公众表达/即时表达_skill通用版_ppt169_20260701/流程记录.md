## Step 4: 设计稿

### A 部分（人看）

#### P01 封面
```
┌─────────────────────────────────────┐
│           即时表达                   │
│        公众发言的核心艺术             │
│         ─── 表达力训练 ───           │
│  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  │ ← 底部渐变带
└─────────────────────────────────────┘
风格：居中标题 + 底部渐变色带
```

#### P02 表达本质（左右对比）
```
┌───────────────┬──────────────────────┐
│ ■ WHAT        │ ■ HOW                │
│ 表达内容       │ 表达方式              │
│ ● 前端        │ 本质：认知压榨        │
│ ● 后端        │ ① 流畅性启发          │
│ ● 护城河      │ ② 场景表达模式        │
│ 半书面=...    │ 更重要的是表达方式    │
└───────────────┴──────────────────────┘
```

#### P03 四大原则（纵向编号列表）
```
┌─────────────────────────────────────┐
│ 00  目的决定形式                     │ ← 浅灰底
├─────────────────────────────────────┤
│ 01  时间有限性                       │ ← 浅灰底
├─────────────────────────────────────┤
│ 02  时间线性                         │ ← 浅灰底
├─────────────────────────────────────┤
│ 03  认知带宽                         │ ← 深色强调
└─────────────────────────────────────┘
```

#### P04 权威来源（双圆Venn）
```
    ╭───╮       ╭───╮
    │信任│ ╳     │权威│
    │情感│       │理性│
    ╰───╯       ╰───╯
    
  [信任结论框]  [权威结论框]
```

#### P05 流畅性启发（中心辐射）
```
        [说明条]
    [绿框] ← ●核心● → [红框]
    
    [启示带：流畅比正确更重要]
    [策略1] [策略2] [策略3]
```

#### P06 场景表达（纵向阶梯+范例）
```
  ┌─STEP1─钩子──────────┐  ┌─范例──────┐
  ┌─STEP2─结论────────┐  │           │
  ┌─STEP3─观点──────┐  │  │ 钩子+结论 │
  ┌─STEP4─行动────┐  │  │ 观点      │
                   │  │ 行动      │
```

#### P07 实战模板（三列+标签）
```
  [1结论]  [2理由]  [3建议]
  
  [自信] [严谨] [口语化] [短句] [避免术语]
  
  [完整范例框]
  [核心金句条]
```

#### P08 总结
```
  [01 目的决定形式]  [02 尊重注意力]
  [03 信任与权威]   [04 流畅性启发]
  [05 场景公式 ──────────────────]

```
