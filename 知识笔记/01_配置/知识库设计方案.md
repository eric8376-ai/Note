## 一、设计理念

### 1.1 核心架构：四层知识体系

```
第一层：数据源（DataSources）     → 原始内容仓库，按来源+年份组织
第二层：摘要（Summaries）         → 来源的索引，一一对应
第三层：主题卡片（Cards）         → 原子化知识单元，跨来源连接
第四层：自我笔记（SelfNotes）     → 个人创造，PARA框架组织
```

### 1.2 组织原则

| 层次 | 组织原则 | 分类方式 |
|------|----------|----------|
| 第一层 | 按来源+年份 | 文件夹（类型/年份） |
| 第二层 | 按来源+年份 | 文件夹（与第一层对应） |
| 第三层 | 按概念本体 | 标签 + MOC |
| 第四层 | 按行动 | PARA框架 |

### 1.3 知识类型区分

- **社科类**（观点驱动）：适合卡片盒法，自由连接
- **学科类**（体系驱动）：保持章节结构，建立概念图谱

## 二、入库工作流

### 2.1 核心流程

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   新文件    │ ──→ │   inbox/    │ ──→ │  AI入库     │
│ (任意来源)  │     │  (缓冲区)   │     │  (自动整理)  │
└─────────────┘     └─────────────┘     └─────────────┘
                           │                    │
                           │  入库成功后删除 ←───┘
                           ↓
                    ┌─────────────┐
                    │  缓冲区清空  │
                    └─────────────┘
```

### 2.2 用户操作

1. **放入文件**：把新文件（书籍MD、视频字幕、文章、AI对话）直接丢到 `inbox/` 目录
2. **通知AI**：告诉AI「入库」或「整理inbox」
3. **AI自动处理**：
   - 扫描inbox/目录
   - 识别文件类型
   - 重命名并移动到正确位置
   - 生成摘要（如适用）
   - 提取概念卡片（如适用）
   - 更新MOC索引
   - **入库成功后删除inbox中的原文件**
4. **Git同步**：整个目录定期自动提交到Git

### 2.3 AI入库规则

| 文件类型 | 识别特征 | 处理方式 |
|----------|----------|----------|
| 书籍 | 篇幅长、章节结构 | 移动到10_数据源/11_书籍/，生成摘要 |
| 视频字幕 | 时间戳、口语化 | 移动到10_数据源/12_视频/，生成摘要 |
| 文章 | 中等篇幅、结构化 | 移动到10_数据源/13_文章/，生成摘要 |
| AI对话 | 对话格式、多轮问答 | 移动到10_数据源/14_AI对话/，生成摘要 |
| 已整理的摘要 | 标题含"摘要" | 移动到20_摘要/对应目录 |
| 已整理的卡片 | 类型标签、概念卡片特征 | 移动到30_主题卡片/对应目录 |

## 七、AI入库操作指南

### 7.1 入库命令

用户可以说：
- 「帮我整理temp目录」
- 「入库」
- 「整理一下temp」

### 7.2 AI入库流程

```
1. 扫描temp/目录
2. 识别每个文件的类型
3. 按规则重命名
4. 移动到正确目录
5. 如需要，生成摘要和卡片
6. 清空temp/目录
7. 报告处理结果
```

### 7.3 源文件清理规范

如果原始文件内容混乱（如AI对话记录、OCR识别结果），AI应先整理再入库：

**清理规则**：
| 问题 | 处理方式 |
|------|----------|
| 对话格式杂乱 | 整理为问答结构，去除重复、口误 |
| 时间戳/标记符 | 去除或转换为结构化格式 |
| 内容跳跃 | 按主题重新组织，添加小标题 |
| 口语化严重 | 保留核心观点，精简冗余 |

**原则**：
- 保留原始信息的完整性
- 提升可读性和检索效率
- 摘要和卡片从清理后的版本提取

### 7.4 处理示例

**输入**：inbox/豆包文集/丛林法则.md（原始对话，格式混乱）

**AI处理**：
1. 识别为AI对话记录
2. **清理源文件**：按主题重新组织，添加章节标题，去除口语冗余
3. 保存清理版到 `10_数据源/14_AI对话/2026/0317_豆包_丛林法则与权力.md`
4. 生成摘要到 `20_摘要/24_AI对话摘要/2026/`
5. 提取概念卡片（资源整合能力）到 `30_主题卡片/31_概念/`
6. 删除inbox中的原文件
