# 两性关系中的强者思维与权力博弈_摘要

## 核心主题
男性成长、两性关系中的权力博弈与吸引力法则（93个视频合并）

---

## 核心概念

| 概念 | 定义 |
|------|------|
| 主体性 | 稳固的自我认同感，不对异性献媚的态度 |
| 筛选 | 在对自己感兴趣的异性中进行选择，而非追求 |
| 框架测试 | 女性通过假设或考验观察男性的异性缘和是否容易被带领 |

---

## 核心观点

### 一、关系本质是博弈
- 所有关系（包括婚姻）本质上都是博弈
- 任何长期关系都是不可持续的
- 女性口中的"好男人"=拥有资源却不懂得维护自身权益的男性

### 二、强者思维

| 要素 | 说明 |
|------|------|
| 主体性 | 从自身原因出发主导行为 |
| 规则 | 任何事物拿来就用，用不了就换 |
| 信念 | 基于基因与利益的双重价值发挥实质作用 |

**建立主体性 = 建立吸引力**

### 三、筛选而非追求

| 追求 | 筛选 |
|------|------|
| 把自己摆在低位 | 在感兴趣的异性中选择 |
| 掉价行为 | 保持选择权 |
| 让不喜欢你的人喜欢你（大忌） | 让喜欢你的人更喜欢你 |

### 四、框架测试应对

| 错误 | 正确 |
|------|------|
| 服软妥协 | 拒绝或设置回报条件 |
| 唯唯诺诺 | 保持自身姿态 |
| 疯狂讨好 | 将对方视为"小朋友" |

**聊天技巧：** 展露小攻击性 → 几个来回后占上风 → 重复过程

### 五、吸引力的本质

- **女性眼中的帅**=感觉+人设，不是客观的
- **男性眼中的美**=外貌吸引力，相对客观
- 女性更痴迷于无法完全掌控的感觉

### 六、避免被驯化

- 如果女人说你是"好人"=失去吸引力
- 女性慕强又惧强：被驯化后就成了弱者
- 必须一直强，还要时不时在精神上压制对方

### 七、交易思维 vs 投资思维

| 投资思维 | 交易思维 |
|----------|----------|
| 花时间和价值在对方身上 | 不花时间和价值 |
| 期待回报 | 即时交换 |
| 容易被寄生 | 保持主动权 |

### 八、长期关系的困境

- 任何长期关系都不可持续
- 男人由强变弱的催化剂：错把"寄居属性"当"定居属性"
- 两团复杂变量不可能一直相互吸引

---

## 核心要点总结

1. **关系本质是博弈** - 没有这种意识就不成熟
2. **筛选而非追求** - 追求本身就是掉价的行为
3. **建立主体性** - 建立自身就等于建立吸引
4. **交易思维** - 不能用投资思维
5. **保持框架** - 不服软、不妥协、设置回报条件
6. **避免被驯化** - 必须一直强，还要时不时压制对方
7. **态度决定标准** - 无所谓态度反而降低对方要求
8. **长期关系不可持续** - 两团复杂变量不可能一直相互吸引
