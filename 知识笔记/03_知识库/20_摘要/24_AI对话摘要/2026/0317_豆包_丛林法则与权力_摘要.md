# 丛林法则与权力 - AI对话摘要

## 核心框架

### 动物权力逻辑
```
武力 = 保护力 = 繁殖权 = 权力
```

### 人类权力演变
```
武力 → 经济能力、智慧、社会资源 → 资源整合能力
```

## 关键概念

### 资源整合能力
把不同人的技能、资源协调起来，产出更大价值。核心是知道"谁适合做什么，怎么组合效率最高"。

### 权力 vs 领导力
| 维度 | 权力 | 领导力 |
|------|------|--------|
| 方式 | 削弱对手 | 带着大家一起变强 |
| 目标 | 让团队听话 | 让大家相信目标 |

### 亲密关系四要素排序
1. 一起对抗风险的**意愿**（最重要）
2. 对抗风险的**能力**
3. 物质供养的**能力**
4. 物质供养的**意愿**

## 关键洞见

### 吸引力的本质
> "对抗风险的才能" = 给对方提供"确定性"

不是钱或强壮，而是"可依靠的稳定感"。

### 能力 vs 意愿
- 意愿易变，能力稳定
- 但能力能否为你所用，取决于意愿的"开关"
- 有能力无意愿 = 能力永远不属于你

### 分寸原则
> 责任我扛，锅我不背；困难我陪，绑架我拒。
