# 信息茧房

## 定义

人们只关注自己选择的内容、让自己感到愉悦和认同的领域，久而久之被单一信息和观点束缚的状态。

> 由美国学者**凯斯·桑斯坦**提出

## 形成原因

| 原因 | 说明 |
|------|------|
| 选择性心理 | 天生倾向于接触与自己观点相符的信息 |
| 算法推荐 | 根据行为数据不断推送同类内容 |
| 社交圈层化 | 只与志同道合的人互动，观点被强化 |

## 核心危害

### 1. 失去反馈机制
- 正常世界：行动 → 负反馈 → 调整改进
- 茧房世界：算法只讨好不纠正 → "我永远正确"的幻觉

### 2. 信念陷阱
观点 → 身份固化 → 无法回头
```
"我认为A更好" → "支持A的人聪明" → "我聪明，他们低劣"
```

### 3. 人际关系恶化
- 共情力被偏见遮蔽
- 妥协力被自恋消解
- 只能在虚拟世界找到附和者

## 破解方法

1. **主动接触异见** - 关注不认同的观点
2. **跨出社交圈** - 与不同背景的人交流
3. **多元化信源** - 不只依赖算法推荐
4. **批判性思维** - 问"这是事实全部吗？"
5. **反人性练习** - 定期寻找讨厌观点的合理之处
