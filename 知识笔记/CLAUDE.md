## 四层知识架构

| 层次 | 目录 | 内容 | 组织方式 |
|------|------|------|----------|
| 第一层 | `03_知识库/10_数据源/` | 原始内容（书籍/视频/文章/AI对话） | 按来源+年份 |
| 第二层 | `03_知识库/20_摘要/` | 来源摘要（一一对应第一层） | 与第一层对应 |

| 第四层 | `03_知识库/40_自我笔记/` | 个人创造 | PARA框架 |

## 入库工作流

```
新文件 → 02_缓冲区/ → AI识别类型 → 整理源文件 → 存入数据源 → 生成摘要 → 清空缓冲区
```

### 入库核心原则

> **先整理，后入库，便于溯源**
> - 数据源保留完整原文，是知识溯源的唯一依据
> - 源文件必须整理后再存入，不是原始堆砌
> - 摘要从数据源提取，两者一一对应

### 入库规则（执行顺序）

**第一步：识别文件类型**

| 文件类型 | 数据源目录 |
|----------|------------|
| 书籍 | `03_知识库/10_数据源/11_书籍/{学科}/` |
| 视频字幕 | `03_知识库/10_数据源/12_视频/{年份}/` |
| 文章 | `03_知识库/10_数据源/13_文章/{年份}/` |
| AI对话 | `03_知识库/10_数据源/14_AI对话/{年份}/` |
| 其他 | `03_知识库/10_数据源/15_其他来源/{年份}/` |

**第二步：整理源文件（必做）**

| 问题 | 整理方式 |
|------|----------|
| 格式杂乱 | 统一为 Markdown，添加层级标题 |
| 对话冗长 | 提取核心问答，去除寒暄/重复 |
| 时间戳/标记符 | 去除无用标记，保留有价值元信息 |
| 内容跳跃 | 按主题重新组织，添加小标题 |

**第三步：存入数据源 + 生成摘要**

- 摘要存入 `03_知识库/20_摘要/` 对应目录
- 摘要与数据源一一对应
