## 📖 核心理念

### 五大方法论融合

```
卡片笔记（采集）→ 双链笔记（连接）+ PARA（组织）→ 第二大脑（沉淀）→ AI驱动（检索）
```

### 四层知识架构

| 层次 | 内容 | 作用 | 组织方式 | 创建者 |
|------|------|------|----------|--------|
| 第一层：数据源 | 原书/视频/对话 | 原文仓库 | 按来源 | AI+工具 |
| 第二层：摘要 | 7维度摘要 | 快速索引 | 按来源 | AI |
| 第三层：主题卡片 | 原子化知识 | 知识单元 | 标签+MOC+AMOC | AI初稿+人完善 |
| 第四层：自我笔记 | 个人创造 | 原创产出 | PARA框架 | 人 |

### 书籍的七个价值维度

| 维度 | 作用 | 使用场景 |
|------|------|---------|
| 概念 | 知识原子 | 理解核心思想 |
| 定义 | 精确理解 | 学术写作、辩论 |

## 🔗 AMOC双链框架

**核心**：用 `up:: [[上级索引]]` 属性 + Dataview 自动生成索引

### 三步骤

1. **上级索引**：在笔记中写 `up:: [[上层目录]]`
2. **同级索引**：用Dataview列出同一上级的所有笔记
3. **下级索引**：用Dataview列出指向当前笔记的所有子笔记

### 优势

- 不依赖文件夹路径
- 不依赖标签系统
- 修改笔记名自动同步
- 专注笔记本身

## 🔄 工作流

### 入库流程

```
新文件 → 缓冲区/ → AI识别类型 → 整理源文件 → 存入数据源 → 生成摘要 → 清空缓冲区
```

### 入库核心原则

> **先整理，后入库，便于溯源**
> - 数据源保留完整原文，是知识溯源的唯一依据
> - 源文件必须整理后再存入，不是原始堆砌
> - 摘要从数据源提取，两者一一对应

### AI入库规则（执行顺序）

**第一步：识别文件类型**

| 文件类型 | 识别特征 | 数据源目录 |
|----------|----------|------------|
| 书籍 | 篇幅长、章节结构 | `10_数据源/11_书籍/{学科}/` |
| 视频字幕 | 时间戳、口语化 | `10_数据源/12_视频/{年份}/` |
| 文章 | 中等篇幅 | `10_数据源/13_文章/{年份}/` |
| AI对话 | 对话格式 | `10_数据源/14_AI对话/{年份}/` |
| 其他 | 不符合以上类型 | `10_数据源/15_其他来源/{年份}/` |

**第二步：整理源文件（必做）**

原始文件必须整理后再存入数据源，便于后续溯源：

| 问题 | 整理方式 |
|------|----------|
| 格式杂乱 | 统一为 Markdown，添加层级标题 |
| 对话冗长 | 提取核心问答，去除寒暄/重复 |
| 时间戳/标记符 | 去除无用标记，保留有价值的元信息 |
| 内容跳跃 | 按主题重新组织，添加小标题 |
| 口语化严重 | 保留原意，精简表达 |

**第三步：存入数据源**

- 按文件类型存入对应目录
- 文件命名遵循规范（见下文）
- 添加 YAML front matter（来源、日期、标签）

**第四步：生成摘要**

- 摘要存入 `20_摘要/` 对应目录
- 摘要与数据源一一对应
- 提取七个价值维度：概念、定义、数据、案例、引文、论证、方法

### 使用方式

1. 把新文件放入 `02_缓冲区/` 对应子目录
2. 告诉 AI「入库」或「整理缓冲区」
3. AI 按上述规则执行：识别 → 整理 → 存入数据源 → 生成摘要
4. 成功后删除缓冲区原文件
5. 定期 Git 同步

## 📚 PARA框架

| 字母 | 英文 | 中文 | 核心问题 | 特征 |
|------|------|------|----------|------|
| P | Projects | 项目 | 我现在要做什么？ | 有截止日期 |
| A | Areas | 领域 | 我长期负责什么？ | 无截止日期 |
| R | Resources | 资源 | 我可能用到什么？ | 按主题组织 |
| A | Archives | 归档 | 哪些已经完成？ | 历史内容 |

### 流动逻辑

```
Resources → 开始项目 → Projects → 结束 → Archives
                              ↑
                      Areas 长期维护
```

## 🤖 AI协同原则

### AI能做

- 提取原子想法
- 推荐可能的连接
- 生成初稿供修改
- 定期聚合相关卡片

### 人必须做

- 判断什么值得记
- 用自己的话重写
- 判断连接意义
- 提炼真正洞察

### 核心原则

> **AI是认知副驾驶，不是自动驾驶**
