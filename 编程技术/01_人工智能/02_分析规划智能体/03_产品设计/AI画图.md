
我其实现在想跟你探讨的是，我需要一套画图的框架。首先是一套描述，我可以简单修改的文字描述。然后根据这套描述，你可以无
  歧义的生成ASCII、Mermaid、drawio这些图。效果保持一致。
你需要的是一个图描述的中间层（DSL），一套描述可以多端渲染。
自然语言描述（人编写/阅读）
          ↓
      AI 解析转换
          ↓
     DSL 中间层（结构化数据）
          ↓
      ┌───┼───┐
      ↓       ↓        ↓
   ASCII Mermaid DrawIO  

 ## 流程：核心业务总览

  ### 阶段
  1. 产品供给
  2. 内容引流
  3. 需求匹配
  4. 线索转化
  5. 佣金结算

  ### 节点
  - 产品供给：产品方提交产品 → 平台审核 → 产品上架
  - 内容引流：平台运营发布内容 → 内容引流 → 客户浏览房产信息
  - 需求匹配：客户浏览房产信息 → (场景推荐 / 智能匹配) → 产生线索
  - 线索转化：产生线索 → (自有销售跟进 / 渠道人员跟进) → 订单完成
  - 佣金结算：订单完成 → 佣金结算

  ### 跨阶段关联
  - 产品上架 ~~关联~~ 客户浏览房产信息（产品可供客户浏览）

  语法约定：

  ┌──────────┬────────────────────────┐
  │   符号   │          含义          │
  ├──────────┼────────────────────────┤
  │ →        │ 顺序连接               │
  ├──────────┼────────────────────────┤
  │ /        │ 分支（或）             │
  ├──────────┼────────────────────────┤
  │ ~~关联~~ │ 虚线连接，括号内为说明 │
  └──────────┴────────────────────────┘
