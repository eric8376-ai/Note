## **事务性等级说明**

| 等级      | 名称   | 描述                            | 适用场景                |
| ------- | ---- | ----------------------------- | ------------------- |
| **L0**​ | 无事务  | 无事务保证，消息可能丢失或重复               | 监控数据、实时日志、游戏状态      |
| **L1**​ | 基本确认 | 消息投递确认，保证不丢失但可能重复             | 通知消息、状态同步、MQTT QoS1 |
| **L2**​ | 本地事务 | 单消息队列内的事务保证，支持commit/rollback | 单一业务操作、RabbitMQ事务   |
| **L3**​ | 事务消息 | 半消息+本地事务+最终确认的二阶段模式           | 分布式事务、电商下单、库存扣减     |
| **L4**​ | XA事务 | 标准XA分布式事务，强一致性，两阶段提交          | 银行转账、金融交易、核心系统      |
| **L5**​ | 流式事务 | 流处理中的Exactly-Once语义，检查点机制     | 实时计算、Flink/Kafka流处理 |

## **关键指标说明**

|指标|说明|影响选择的因素|
|---|---|---|
|**终端数量**​|同时活跃的连接数/客户端数|海量设备选MQTT，少量客户端可选任意|
|**吞吐量**​|消息/秒处理能力 (基于1KB消息)|高吞吐选Kafka/Pulsar，中吞吐选RocketMQ/RabbitMQ|
|**延迟**​|端到端延迟P99值|低延迟选NATS/ZeroMQ，可接受延迟选Kafka|
|**可靠性**​|消息不丢失的概率|金融级选IBM MQ，高可靠选RocketMQ/RabbitMQ|
|**磁盘IO**​|是否支持/需要磁盘持久化|必须持久化选磁盘方案，临时数据可选内存|
|**成本**​|年度部署和维护成本|预算有限选开源，企业级选商业方案|
