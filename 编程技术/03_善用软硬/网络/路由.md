## 增加内网特定IP的路由

192.168.201.54
tracert  192.168.201.54
route add 192.168.201.0 mask 255.255.255.0 188.9.24.1  网段不行
route -p add 192.168.201.54 mask 255.255.255.255 188.9.24.1 metric 1   就精确到具体的IP
route  add 192.168.201.54 mask 255.255.255.255 188.9.24.1 metric 1

检查路由是否成功
route print | findstr 192.168.201
删除路由
route delete 192.168.201.0

您之前添加的路由可能没有 `-p` 参数，重启或网络重连后会丢失
## 默认网关的冲突
1. 删除内网的默认网关（关键！）
route delete 0.0.0.0 mask 0.0.0.0 10.1.20.254
2. 确保外网默认路由存在且优先级高
route delete 0.0.0.0  # 先删除所有默认路由
route -p add 0.0.0.0 mask 0.0.0.0 188.9.24.1 metric 10

# 命令参考
## 查看完整路由表
route print
route print -4
## 只看特定网段
route print | findstr "192.168"
## 添加路由（临时）
route add 目标 mask 掩码 网关
## 添加路由（永久重启有效）
route -p add 目标 mask 掩码 网关
## 删除路由
route delete 目标
## 修改路由（先删后加）
route change 目标 mask 掩码 网关 metric 跃点数
