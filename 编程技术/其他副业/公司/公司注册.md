## 一、6 类核心经营主体对比表

| 主体类型          | 法律依据      | 法人资格 | 责任承担                      | 税收规则                  | 治理与名称规范                                  | 典型适用场景                    |
| :------------ | :-------- | :--- | :------------------------ | :-------------------- | :--------------------------------------- | :------------------------ |
| 个体工商户         | 《个体工商户条例》 | 无    | 个人 / 家庭财产无限责任             | 经营所得缴个人所得税，无企业所得税     | 注册极简，无章程 / 监事；名称禁 “公司”，可用 “店 / 铺 / 工作室”  | 小本零售、餐饮、网店、个人手工等轻资产小生意    |
| 个人独资企业        | 《个人独资企业法》 | 无    | 投资人个人财产无限责任               | 经营所得缴个人所得税，无企业所得税     | 需设账簿，无股东会；名称可用 “中心 / 工作室 / 事务所”，禁 “公司”   | 个人工作室、技术咨询、设计服务等个人主导的专业服务 |
| 合伙企业（普通 / 有限） | 《合伙企业法》   | 无    | 普通合伙人无限连带责任；有限合伙人以出资额为限担责 | 合伙层面不缴企业所得税，合伙人缴个人所得税 | 需合伙协议，普通合伙人负责管理；名称含 “合伙”                 | 投资基金、律师 / 会计师事务所、创意团队合作项目 |
| 一人有限责任公司      | 《公司法》     | 有    | 股东以认缴出资额为限担责（财产混同除外）      | 缴企业所得税 + 分红个税（双重征税）   | 需章程、监事，每年强制审计；名称必须含 “有限责任公司 / 有限公司”      | 需法人资格、风险隔离的个人创业（如科技、贸易）   |
| 普通有限责任公司      | 《公司法》     | 有    | 股东以认缴出资额为限担责              | 缴企业所得税 + 分红个税（双重征税）   | 需股东会 / 董事会 / 监事，财务规范；名称含 “有限责任公司 / 有限公司” | 团队创业、计划融资、长期发展的中小企业       |
| 股份有限公司        | 《公司法》     | 有    | 股东以认购股份为限担责               | 缴企业所得税 + 分红个税（双重征税）   | 注册资本要求高，需董事会 / 监事会，适合上市融资                | 成熟企业、需大规模融资或计划上市的项目       |
